# AI-Engine 开发计划总索引

这里是项目的**唯一权威计划源**。写代码前先读对应的 plan，改方向先改 plan。

## 怎么用这套文档

1. 先读 `00`（要做什么、不做什么）和 `01`（整体架构），建立全局图像。
2. 按里程碑顺序执行。每个 plan 的「实施步骤」是可直接照做的编号清单，「验证命令」用来自证完成。
3. 每完成一个 plan，回到本文件更新进度表的状态。
4. 任何与 plan 不符的技术决策，先在 `20-adr-and-risks.md` 追加一条 ADR，再动代码。

## 依赖关系（不要跳步）

```
02 工程底座
 └─ 03 契约层
     ├─ 04 模型基线 ──┐
     └─ 05 数据层 ────┤
                      ├─ 06 RAG ── 07 对话页
                      ├─ 08 工作流后端 ── 09 工作流画布
                      └─ 10 Agent 工具 ── 11 MCP
                                          └─ 12 双端 ── 13 打包
```

`04` 是隐藏的关键路径：它的实测结论会反过来修改 `10` 的工具数量上限和 `08` 的节点设计。**在 04 完成前不要开工 10。**

## 阅读这套文档时的注意事项

- 文档里出现的所有版本号都是编写时 npm 上的实际最新版，安装时如有更新以 `pnpm outdated` 为准，但**跨大版本升级要先在 ADR 里评估**。
- 文档里的目录结构是目标态，当前仓库还没有这些目录，由 `02` 负责创建。
- 凡是标注「当前信息无法确认」的地方，表示需要实际动手验证后才能填，不要凭猜测补全。
