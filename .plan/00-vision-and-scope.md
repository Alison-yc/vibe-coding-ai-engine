## 范围内（承诺交付）

### 三个核心功能域、一个统一助手入口

**1. 统一 AI 对话助手 + RAG 知识库**（M2/M4，第一个可演示成果）
左侧会话列表，右侧对话区。支持创建知识库、上传文档、基于知识库问答、流式输出、引用溯源；日期、计算、UUID、天气按输入自动使用工具。

**2. 可视化工作流编排**（M3，技术含量最高）
类 Dify 的画布。节点可拖拽、可连线、可配置。节点类型第一批做 8 个：开始、结束、LLM、知识检索、条件判断、变量赋值、代码执行、HTTP 请求。支持节点间变量引用、单节点调试、运行态高亮与执行日志。

**3. 本地文件 Agent 能力**（M4，最能体现对 Agent 的理解）
文件能力不再是独立页面，而是统一对话中的显式“文件访问”开关。开启后可读、写、精确编辑、按 glob 找文件、按内容搜索；每轮继续经过路径沙箱 → 权限规则 → 用户审批。

**4. 界面语言**（增量，ADR-016 / `14-C`）
设置页切换 `zh-CN` / `ja-JP` / `en-US`。只覆盖产品 chrome 与页面文案，不覆盖模型输出、知识库原文、工程文档。布局以英文为最长基准，切换语言不得撑破壳层。

### 交付形态

- 浏览器 Web 应用（`pnpm dev:web`）
- macOS 桌面应用（`.dmg` 安装包，可在设置页配置后端地址与端口）
- 两者共用同一套业务代码，通过平台适配层隔离差异

### 工程能力产出物

- 契约驱动：前后端类型来自同一份 zod schema
- 测试：单元 + 集成 + 契约 + E2E 四层，覆盖率阈值门禁
- LLM 辅助测试：生成用例 → 自动执行 → 覆盖率报告 → 阈值门禁的闭环
- 安全：Semgrep SAST + 依赖 SCA + 轻量 DAST，结果以 SARIF 汇总
- CI：GitHub Actions 分层流水线

## 范围外（明确不做，避免无限膨胀）

| 不做                     | 原因                                                       |
| ------------------------ | ---------------------------------------------------------- |
| 多用户、多租户、权限体系 | 学习项目单用户即可，加了只是重复 CRUD                      |
| 云端部署                 | 模型在本机，部署上云也访问不到；作为未来升级点记录在 20    |
| 云端模型 API 接入        | 同上。LLM 网关会预留 provider 抽象，但只实现 Ollama        |
| 协作编辑（CRDT）         | Dify 有，但与 AI 能力无关，投入产出比低                    |
| 第四种界面语言 / RTL     | 只做中日英，全部 LTR；工程文档与 git 提交仍用中文          |
| CopilotKit               | 面向云端大模型；对话 SSE 需与工作流/Agent 共用。见 ADR-003 |
| 插件市场、插件沙箱进程   | 微内核的插件化通过代码内注册表体现即可                     |
| Windows / Linux 打包     | 只交付 macOS dmg                                           |
| 移动端                   | 无关                                                       |
| Kubernetes、微服务拆分   | 单体 NestJS 足够，拆了只是增加运维负担                     |

## 已知的硬约束（这些不是缺陷，是设计前提）

1. **模型只有 2B 级别。** qwen3.5:2b 的工具调用可靠性、指令遵循能力、长上下文表现都远低于云端大模型。功能设计必须建立在 `04` 的实测数据上，而不是"云端模型能做的它也能做"。
2. **没有 GPU 集群。** 单次推理有明显延迟，所有面向用户的模型调用必须流式输出，并且要有取消机制。
3. **embedding 是 768 维的 nomic-embed-text。** 中文效果一般，检索质量的天花板由它决定，`18` 的评测要如实记录这一点。
4. **单人开发。** 任何需要"团队协作才划算"的工程实践（复杂的 code owner、多环境发布流水线）都不引入。
